 📊 Task 3 - SQL for Data Analysis

 📌 Project Overview
This project demonstrates SQL-based data analysis using the **Sample Superstore Dataset**. The objective was to perform data exploration, filtering, aggregation, joins, subqueries, views, and indexing using MySQL. The project simulates real-world business analysis by extracting meaningful insights from sales data.


 🎯 Objective
- Analyze retail sales data using SQL.
- Practice writing efficient SQL queries.
- Learn data manipulation and analytical techniques using MySQL.
- Generate business insights from transactional data.


 📂 Dataset
Dataset: Sample Superstore Dataset

The dataset contains information about:
- Customer Details
- Orders
- Products
- Categories & Sub-Categories
- Sales
- Profit
- Quantity
- Discounts
- Regions
- States

 📈 Business Questions Solved

The following business questions were answered using SQL:

- Retrieve complete sales records.
- Find products with sales greater than a specified amount.
- Display customers based on different conditions.
- Sort products based on highest sales.
- Calculate total sales by category.
- Calculate average profit by region.
- Count orders by customer segment.
- Identify top profitable products.
- Find total sales generated by each state.
- Calculate total sales and average sales.
- Find maximum and minimum profit.
- Calculate total quantity sold.
- Identify products with sales above average.
- Identify customers generating above-average profit.
- Find the highest sales order.
- Create a SQL View for profitable orders.
- Create an Index to improve query performance.
- Perform INNER, LEFT, and RIGHT JOIN operations using normalized tables.

📊 Business Insights

Based on the SQL analysis, the following insights were observed:

- Technology and Office Supplies are among the highest revenue-generating categories.
- Sales vary significantly across different regions and states.
- Some orders generated negative profit, indicating losses despite successful sales.
- High discounts often resulted in reduced profitability.
- A small group of customers contributed a significant share of total sales.
- Regional sales analysis helps identify high-performing markets.
- Product-wise profit analysis can help businesses optimize inventory and pricing strategies.
