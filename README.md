 Task 3 - SQL for Data Analysis

 Objective
This project demonstrates SQL skills for data analysis using the Superstore dataset.

 Dataset
- Sample Superstore Dataset (CSV)

 Tools Used
- MySQL Workbench

SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions (SUM, AVG, MAX, MIN)
- Subqueries
- Views
- Indexes
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

 Files Included
- Task3_SQL.sql
- Superstore.csv
- Screenshots of SQL query outputs

 Outcome
Performed data analysis on the Superstore dataset using SQL queries and explored filtering, aggregation, joins, views, indexing, and subqueries.
